# ForgeMuscle — AI Workout Verifier & 60s Battle Arena

ForgeMuscle — це платформа верифікації тренувань наступного покоління на стику комп'ютерного зору (MediaPipe Pose), гейміфікованих дуелей та блокчейну Solana.

---

## ⚡ Архітектура та Ключові Модулі

1. **AI Camera Verifier (`/src/services/poseService.ts`, `PushUpVerifier.ts`)**:
   - Відстеження ключових точок скелета (плечі, лікті, зап'ястя, таз, щиколотки) у реальному часі.
   - Суворий розрахунок діапазону руху (>85% ROM для зарахування репу).
   - Детекція типових помилок: неповна амплітуда, відсутність фіксації вгорі (lockout), прогин тазу.
   - Серверний анти-реплей нонс (Anti-Replay Nonce) для захисту від повторного надсилання відеозаписів.

2. **60s Battle Arena (`ForgeBattleArena.tsx`, `forgeGameStore.ts`)**:
   - Реальний динамічний Tug-of-War перебіг бою між атлетами.
   - Серверне чергування підбору суперників (Matchmaking) із **20-секундним тайм-аутом**. Якщо живий суперник не підключається вчасно, інтерфейс автоматично переходить у стан очікування з можливістю спарингу з "Залізним Тарасом" або повторного пошуку без зависань.

3. **Криптографічна Безпека та Акаунти (`server.ts`, `authStore.ts`)**:
   - Паролі хешуються виключно через сучасний стійкий алгоритм `scrypt` із криптографічною сіллю.
   - Захист від підбору паролів (Brute-force protection): ліміт 5 невдалих спроб на 15 хвилин для кожного облікового запису / IP.
   - Повноцінний цикл відновлення пароля (Forgot / Reset Password).

4. **Onboarding Flow (`OnboardingFlow.tsx`)**:
   - Скорочений швидкий онбординг (<60 секунд) без зайвих анкет — прямий вхід у перший калібрувальний тест віджимань перед камерою.

## 🛑 Parked Modules (Парковані модулі)

Модулі поза критичним шляхом (`ForgeChat`, `ForgeCommunity`, `ForgeEducation`, `ForgeMarketplaceStore`) вимкнені за замовчуванням конфігурацією:
```ts
// src/config/featureFlags.ts
ENABLE_PARKED_MODULES: false
```
При ручному увімкненні прапорця кожен із цих модулів містить чіткий інформаційний банер **«Функція в розробці (Паркований модуль)»**, щоб не дезорієнтувати користувачів.

## ⚠️ Known Limitations (Відомі обмеження)

1. **Освітлення та ракурс камери**: Для коректного зчитування скелета MediaPipe Pose атлет повинен знаходитися у кадрі повністю (від голови до стоп у положенні планки) при контрастному освітленні.
2. **Матчмейкінг у 60s Battle**: Якщо суперник не знайдений протягом 20 секунд, сесія переходить у стан `waiting`, запобігаючи нескінченному пошуку. Доступний офлайн-спаринг.
3. **Обмеження спроб входу (Rate-Limiting)**: Після 5 помилкових спроб введення пароля вмикається примусове охолодження на 15 хвилин.
4. **Devnet RPC та Solana Signatures**: За нестабільного відгуку публічних нод Solana Devnet формується локальний підписаний сервером криптографічний конверт (Proof Hash), який автоматично синхронізується при відновленні зв'язку.
5. **Мобільні браузери (iOS Safari)**: Доступ до камери вимагає явного дозволу користувача при кожному сеансі через політику безпеки WebRTC.
